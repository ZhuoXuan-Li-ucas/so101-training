## 操作流程

1. 用下方 setup 命令启动。连接时关闭双臂力矩，请支撑双臂。
2. 摆出主臂握把竖直、从臂夹爪横向的参照姿态，按 **c**。
   偏移为“从臂腕转角度减主臂腕转角度”。仅腕转使用同方向 1:1 加偏移，其余关节不改映射。
   开启跟随前可按 c 重采。采样不写电机寄存器。
3. 在合法范围内对齐双臂，按 **a** 开启映射跟随，用主臂选定开阔、空爪的初始姿态。
   若已手动摆好并对齐，可不按 a，直接进行下一步。
4. 两臂停稳、夹爪空且张开时按 **h**，保存实际初始姿态及腕转偏移。
   保存不改变力矩，也不发出回位命令；若此前正在跟随，保存后继续握住主臂。
   文件绑定两臂端口、ID、新校准 SHA-256；存在即拒绝覆盖。
5. 按 **r · 空爪复位到初始姿态**。程序读取两臂各自当前实测位置，先保持，倒计时后平滑返回。
   不用先到固定入口，复位起点也不要求两臂映射已经对齐。
6. 到位后双臂保持；按 **s** 接回跟随。支撑双臂后按 **q / Esc** 退出并关闭力矩。

尚未保存腕转映射和初始姿态时，follow、teleop、record 模式都会拒绝启动，不会默认为零偏移。
c 在开启跟随后、以及保存 h 后不再改变偏移。需要改变初始姿态时，另选新的 home 文件路径，
重新审核命令，避免改变既有采集坐标定义。

四次都在下一轮完整读取时恢复，观测间隔约 33.7–34.7 ms；这不是精确测得的实际供电掉压时长。

结果只支持静止、力矩关闭场景下的短时反馈异常，尚未证明运动、复位或录制时无影响。

当前软件处理如下，实机尚未重新验证：

- 只有**主臂力矩关闭**、实际读数低于该关节既有下限，且没有其他故障时进入复核。
  允许低读数附带电压错误位 bit 0；这是确认其是否及时清除，不是屏蔽或写清错误位。
- 最多给 **50 ms** 确认预算，每次完整读取主臂六关节反馈，读取之间等待 **2 ms**。
  需要连续 **2 次**所有关节电压均处于原保护范围内、故障位清零、力矩仍为关闭。
  任何再次异常都会重置连续正常次数；超时或通信失败则停止。
- 复核同步发生在观察阶段，期间不发送新的运动目标、不新增训练帧。
  成功后仅用最后一份完整、最新的反馈产生原始位置、归一化位置和后续动作；不拼接新旧样本。
  不把异常反馈写入训练帧，不用旧位置代替当前位置。复核可能延长该次控制周期，实机频率仍需验收。

  恢复提示在界面显示 5 秒。持续低压或错误位未清除、过压、其他故障、通信失败、非有限值、
  力矩状态不符，以及从臂或使能力矩的主臂异常，仍停止并清理。
  双臂倒计时/复位期间主臂已使能力矩，因此继续执行原来的立即停止规则。

## 暂停与数据语义

手动跟随时，有限的主臂/映射目标越界进入 LIMIT_PAUSED，非法目标不发送。
从臂保持、主臂自由，画面与健康监测继续。映射重新对齐后按 m 恢复，不自动追赶暂停期间的动作。
有已保存初始姿态时，也可在两臂各自回到合法范围后直接按 r 复位，无须先互相对齐。

录制中越界会异步作废当前未保存 episode，完成数不增加。按 m 恢复后为不录制的手动阶段，
按 r 复位后才可 s 重录。等待丢弃完成期间不会开始复位运动。

正式 record 模式有两个结束操作：

- **n：成功保存并复位**。保存完成后才从当前姿态复位，成功计数仅增加一次。
- **r：复位 / 作废重录**。当前未保存片段作废，完成数不增加；已保存的成功段保留。

复位、倒计时、等待和整理过程不写训练帧。每段最多 120 秒，届时停止录帧并保持双臂，
由用户选择成功或失败。首条成功段复位后进入 FIRST_REVIEW，检查视频、数值和任务完成情况，
按 v 确认后继续。第七条也复位，再退出。摆好积木后由用户按 s 开始下一段。

`observation.state` 仍是从臂六维实测位置，`action` 仍是实际发送的从臂六维目标；
腕转偏移已包含在 action 中。原始诊断值只进入会话日志。
