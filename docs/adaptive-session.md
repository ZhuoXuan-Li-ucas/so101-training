主臂使用已确认的独立 5 V 电源。窗口中按以下顺序操作：

快捷键只在预览窗口获得焦点时生效；先点击该窗口，或直接点击按钮。
在聊天框或其他应用输入文字不会触发示教命令。终端 Ctrl+C 仍可结束进程。

1. 支撑双臂，摆出**主臂握把竖直、从臂夹爪横向**的参照姿态，按 `c`。
   计算 `偏移 = 从臂腕部角度 - 主臂腕部角度`，界面显示实际值。
   若第一次姿态不合适，在 `ALIGN`（等待对齐）阶段重新摆好双臂，再按 `c` 即可更新偏移。
   采样只更新内存中的软件映射，不使能力矩、不发送位置目标，也不立即保存文件。
   开启跟随后及路径保存后，`c` 不再改变映射；实际偏移由本次姿态测量，不预设为 ±90°。
2. 在扭矩关闭时手动对齐其他关节，使两臂映射后接近，握住主臂，按 `a` 开启从臂跟随。
3. 遥操到固定的**空旷回程入口**，确认已经松爪、没有夹持积木。等待从臂到位，按 `t`。
4. 保持夹爪张开，示教退离积木、经过空旷区域、返回希望作为每段起点的位置。
   路径应持续 1–120 秒。到起点后停稳，按 `n` 保存；当前位置成为固定起点。
5. 保存成功后双臂保持。支撑双臂，按 `q` 退出。

给两个位置命名有助于理解：**A=每段录制的固定起点，B=完成叠放后进入回程的空旷位置**。
初始参照和对齐阶段手动摆两臂；按 `a` 开启跟随后，回程示教全程操作主臂，让从臂跟随。
先通过主臂遥操找一个夹爪张开、远离积木、便于接管且没有关节接近极限的 A，记住它。
随后遥操到 B，按 `t`；操作主臂示教 **B→A**，停稳按 `n`。
保存的是按 `n` 时的实际起点和整条回程，A 没有单独的提前保存按键。
以后每段录制为 **A→抓白块叠红块→松爪→遥操到 B→按 n 自动返回 A**。
回程示教保持空爪，积木在段间由操作者手动摆回。

`r` 丢弃当前路径，回到入口后按 `t` 重教。参照采样只改变软件映射，
不改写电机校准。示教文件绑定双臂端口、ID 和校准 SHA-256；校准变化后须重新示教。
回程夹爪位置须保持在入口值附近（5 个百分点内）。程序不能识别是否仍夹着物体，
操作者需确认松爪后才申请回程。

### 2. 映射遥操及空旷环境回程测试

```bash
bash /home/pangk/workspaces/so101-training/scripts/so101_session.sh \
  --config /home/pangk/workspaces/so101-training/configs/so101_adaptive.proposed.json \
  --mode teleop
```

先摆到对应姿态，握住主臂按 `s` 开始跟随。到示教回程入口后，松爪并按 `n`，
程序检查入口、让两臂保持、倒计时后自动回程。到位后等待，握住主臂按 `s` 接回遥操。
此阶段不创建训练数据集。先在空旷台面验证，再放置积木测试。

| 自动回程参数 | 值与作用 |
| --- | --- |
| 入口/起点姿态容差 | 每个臂关节 5°；夹爪 5 个百分点。是姿态检查，不是正常跟随的每次目标限额 |
| 倒计时 | 2 秒，两臂保持；此时松开主臂 |
| 入口衔接 | 1 秒，从当前近入口姿态平滑插值到示教首帧 |
| 回放 | 30 Hz；示教速度的 50%，即路径时间的两倍；不修改舵机速度/加速度寄存器 |
| 到位 | 双臂到起点且映射一致，持续 0.5 秒；路径结束后最多等待 5 秒 |
| 跟踪异常 | 臂关节偏差超过 15°或夹爪超过 20 个百分点，持续 0.5 秒则停止 |
| 循环停顿 | 超过 0.5 秒不继续下发轨迹；串口读取超时为 100 ms，相机帧最大年龄 500 ms |

回程是示教路径回放，不是任意姿态避障规划。入口不符时，按 `m` 手动整理到入口，
然后再按 `n`。`m` 要求映射已经对齐，不会强行跳到主臂位置。
若两臂无法对齐，先支撑并退出，关闭扭矩后手动调整再启动。
开启跟随前对照“从臂映射请求”和“从臂实测”两行，逐项调整到允许误差以内。
腕部已经包含偏移，不要求两臂腕部原始数值相同。
软件停止响应依赖系统调度和串口通信，不等同于硬件急停。
